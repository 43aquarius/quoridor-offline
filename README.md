# 步步为营 · QUORIDOR（单机版）

> 一册会下棋的限量印刷棋谱专著 —— risograph 双色套印美学 × 完整 Quoridor 策略对弈。

纯单机策略对弈游戏，基于经典桌面游戏 **Quoridor（步步为营）** 规则。整个应用被排版成一本「编辑部出品的限量棋谱专著」：封面、目录、编者按、档案馆一应俱全；纸白底、墨黑字、荧光红 / 钴蓝双色套印，0.5pt 细线棋盘，铅字棋子与铅条挡板，处处是印刷细节。棋盘尺寸、挡板数量、棋钟规格皆可自定义，支持单人对 AI、双人同屏、四人围坐三种模式，**完全离线运行，无任何网络请求**。

开源仓库：<https://github.com/43aquarius/quoridor-offline>

> 完整版（含在线对战）见：<https://github.com/43aquarius/quoridor>

## 玩法速览

### 二人局（经典）

两名棋手各执一枚棋子，从己方底线出发，目标是最先抵达**对方的底线**（任意一列均可）。

1. **行棋**：轮到己方时，将棋子移动到相邻格（上下左右一格）。
2. **放板**：也可以把一根 2 格长的挡板放在格线凹槽上，用来延长对手的最短路 —— 挡板不可重叠、不可十字交叉，且**不得封死任何一方通往底线的全部路径**（放板后仍须保证双方各有通路）。
3. **跳子**：两枚棋子相邻时，可以直跳过对方；若直跳落点被挡板封住，则可以斜跳到对方左右两侧的格子。
4. **胜负**：先抵达对方底线者胜；认输、总时长耗尽或单步超时判负。

### 四人围坐（FOUR-TABLE）

四名棋手分列棋盘四边中点（甲南 / 乙北 / 丙西 / 丁东），**目标是自己出发边正对面的那条边**（任意一格均可）：甲赴顶行、乙赴底行、丙赴右列、丁赴左列。

1. **行棋顺位**：按顺时针轮转 —— **甲 → 丙 → 乙 → 丁**（南 → 西 → 北 → 东）。
2. **每人挡板减半**（九路经典围坐每人 5 根）：放板后须同时保住**四位在场席位**各有一条通往目标边的通路。
3. **出局制**：认输、超时不再是终局，而是该席**出局**——铅字留在盘上作障碍、不再行棋；当仅剩一席时，末位以「末位收笔」获胜。当然，任何席位率先抵达目标边即立刻获胜。
4. **AI 代打**：每席可独立选真人 / 编辑部 AI（四档任选），凑不齐人也能开局。

四人局启用专属四色套印：**甲 荧光红 / 乙 钴蓝 / 丙 苔绿 / 丁 墨黑**（`.fourp` 色域钉死，不受皮肤切换影响）。

挡板是稀缺资源：全押在进攻上，自己的归途便无人设防；全用来堵对手，对手可能绕出更长的活路。这即是「步步为营」的核心张力。

完整规则与双色图示见应用内「规则 · 编者按」。

## 功能特性

### 三种对弈模式

| 模式 | 说明 |
| --- | --- |
| **单人对弈** | 与「编辑部」四档 AI 对战：学徒 / 排字师 / 总编 / 社长，棋力单调递增 |
| **双人同屏** | 一册棋盘两副活字，回合切换时纸面轻轻换页（视角 cross-fade） |
| **四人围坐** | 本地同屏四人（每席真人 / AI 任选）；出局制、四色套印 |

### 对弈体验

- **最新一手高亮**：每一手棋落定后，行棋落点以四角裁切角标标出、起点留空圈、起讫以点状轨迹相连；落板则围一圈虚线校对圈 —— 回放后一眼可辨，直到下一手才转移。
- **着法记谱**：代数记谱（`e2→e3` / `WALL h4-H`），随棋盘尺寸自动缩放；边栏可逐手回放。
- **悔棋**：单机模式可撤回（人机对局自动撤两手到轮到你）。
- **档案与海报**：终局可入「棋谱档案馆」（localStorage 卷宗，含最远归途峰值、最早耗尽挡板等数据小注）；可导出 1440×2040 棋谱海报 PNG。
- **放板交互**：hover 即预览（合法显己色、非法显红并注明原因），R 键 / 右键翻转横竖；触屏两步放板（先选方向再确认）。
- **视觉与听觉**：四套 riso 双色皮肤（红蓝 / 红黑 / 蓝黑 / 墨绿黑）可刮选切换；活字咔哒、铅条滑入、印章闷响等 Web Audio 合成音效，可开关。

### 自定义开本

棋盘尺寸与挡板数量是一等参数（详见[自定义配置](#自定义配置)），引擎、AI、记谱、海报全链路按 N 路适配；旧存档自动回填 9×10。

### 完全离线

本版本移除了全部联网功能：无网络请求、无网络权限，静态导出后可托管于任意静态空间，或直接打包进离线 APK。

## 快速开始

环境要求：[Bun](https://bun.sh) 1.x（或 Node 20+，以下命令以 bun 为例）。

```bash
# 安装依赖
bun install

# 启动开发服务器（端口 3000）
bun run dev
```

应用：<http://localhost:3000>

## 部署

纯静态导出，产物在 `out/` 目录，任意静态托管均可：

```bash
# 构建（输出到 out/）
bun run build

# 本地预览产物
bun run start
```

## 自定义配置

### 开本（棋盘尺寸 × 每方挡板数）

**二人局预设**：

| 预设 | 棋盘 | 挡板 | 定位 |
| --- | --- | --- | --- |
| 袖珍 MINI | 5×5 | 5 | 速弈短打，十分钟见分晓 |
| 沙龙 SALON | 7×7 | 8 | 轻量对坐，攻守两三回合定调 |
| **经典 CLASSIC** ★推荐 | 9×9 | 10 | 标准赛制，规则书的原排版 |
| 大师 MASTER | 11×11 | 12 | 长卷博弈，绕路更长心机更深 |

**四人围坐预设**（每人挡板约减半）：

| 预设 | 棋盘 | 每人挡板 | 定位 |
| --- | --- | --- | --- |
| 袖珍围坐 MINI TABLE | 5×5 | 3 | 四人速弈，一盏茶见分晓 |
| 沙龙围坐 SALON TABLE | 7×7 | 4 | 轻量四人局，挡板金贵 |
| **经典围坐 CLASSIC TABLE** ★推荐 | 9×9 | 5 | 官方四人赛制，规则书的围桌排版 |
| 大师围坐 MASTER TABLE | 11×11 | 6 | 长桌博弈，三方博弈更长心机 |

- 自定义尺寸档位：**5 / 7 / 9 / 11 / 13 路**（须为奇数，保证中列存在）。
- 自定义挡板数：**0 – 20 根**（滑杆微调）；改尺寸自动套用编辑部推荐值（二人：5→5、7→8、9→10、11→12、13→14；四人：5→3、7→4、9→5、11→6、13→7），可一键恢复推荐。
- 单人、双人、四人围坐均在开局前选开本。

### 棋钟（总时长 + 单步限时）

| 预设 | 总时长 | 单步限时 | 定位 |
| --- | --- | --- | --- |
| 悠然 UNLIMITED ★默认 | 不限 | 不限 | 读本默许慢慢下 |
| 快棋 BLITZ | 3 分钟 | 15 秒 | 电光石火 |
| 标准 STANDARD | 5 分钟 | 30 秒 | 赛钟常规 |
| 长卷 DELUXE | 10 分钟 | 60 秒 | 慢工细活 |

- 自定义总时长档位：不限 / 1 / 3 / 5 / 10 / 20 / 30 分钟（上限 2 小时）。
- 自定义单步时限档位：不限 / 10 / 15 / 20 / 30 / 60 / 120 秒（上限 1 小时）。
- 判定规则：**总时长耗尽判负；单步超时判负**，由本地时钟钩子触发。AI 行动不消耗你的时间。

## AI 棋力

四档以编辑职位命名，难度严格递增（阶梯基准实测：弱代理胜学徒 63%、胜排字师 13%、胜总编 / 社长 0%；中代理可胜学徒与排字师、对总编 / 社长 0%）：

| 档位 | 职位 | 引擎 | 特点 |
| --- | --- | --- | --- |
| L1 | 学徒 | 最短路贪心 + 16% 随机放板 | 懂得直奔终点，尚不懂得设局 |
| L2 | 排字师 | 浅层搜索（深度 2，路径差增益排序） | 聪明的贪心，会沿你的最短路选板 |
| L3 | 总编 | Negamax + α-β 剪枝 + 迭代加深 + Zobrist 置换表 + 杀手着法 / 历史启发 | 评估：路径差（随挡板耗尽权重攀升）、挡板存量、机动空间、行棋权 |
| L4 | 社长 | 总编引擎全预算（更深 / 更宽 / 更久），终局纯竞速精确判胜 | 搜索预算与深度上限随棋盘尺寸缩放 |

AI 全档在 **Web Worker** 中运行不阻塞 UI；搜索时间预算 280ms–2.2s 按档位与尺寸缩放；支持 5–13 路全部开本。开发时可用环境变量 `QUORIDOR_AI_DEPTH / QUORIDOR_AI_WALLS / QUORIDOR_AI_ROOT` 覆写参数做实验。

**四人围坐 AI**（`ai4.ts`）沿用同一套四档人设，评估改为席位感知：计算自己与**其余三席**的路径差、把出局席位的铅字视作障碍物、放板须同时保住四席通路。

## 技术栈

- **框架**：Next.js 16（App Router + Turbopack，静态导出）· TypeScript 5
- **样式**：Tailwind CSS 4 · framer-motion 动效 · 自定义 riso 设计系统（无 UI 框架依赖的棋盘全部手绘 SVG）
- **状态**：zustand（全局状态机）
- **AI**：Web Worker + 自研 Negamax 搜索
- **音效**：Web Audio API 实时合成（零音频资源）
- **持久化**：localStorage（存档续读 / 档案馆 / 皮肤 / 音效开关 / 配置）
